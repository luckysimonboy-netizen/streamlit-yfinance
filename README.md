# Simon Stock V13 Foundation
AI-native US equity research foundation.

Pipeline: Data → Quant → Fundamental → Valuation → Risk → Specialist AI → Bull/Bear Debate → Chief Judge

Includes market/macro data, technical indicators, fundamental scoring, valuation checks, daily news sentiment, six specialist AI agents, adversarial debate, Gemini/OpenRouter/Groq fallback, and system-aware visual styling.

Deploy: upload all files to GitHub, choose `app.py` in Streamlit, install `requirements.txt`, and add API keys to Streamlit Secrets.

Note: yfinance is not a licensed Level-2/dark-pool/millisecond feed; unavailable data is not fabricated.
